# SIA Mahasiswa

Sistem Informasi Akademik sederhana berbasis PHP dan MySQL.

## Fitur

- Login
- Dashboard
- Data Mahasiswa
- CRUD Data Mahasiswa

## Teknologi

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Cara Menjalankan

1. Clone repository
2. Simpan project di folder `htdocs`
3. Jalankan Apache dan MySQL melalui XAMPP
4. Buat database MySQL
5. Buka project melalui browser
